fedoo.ProblemDataSet

class ProblemDataSet(problem, fields=None, assembly=None)

Expose current Problem results through the DataSet interface.

Parameters:

  • problem (ProblemBase) – The live problem. No solve or assembly update is triggered.

  • fields (str or sequence[str], optional) – Results requested through problem.get_results. By default, nodal and global DOFs, external forces and available stress/strain fields are discovered. An explicit list is strict about missing results.

  • assembly (AssemblyBase, optional) – Assembly used by get_results; the problem assembly is the default.

  • before (get_data refreshes from the current problem. Call refresh)

  • return (directly inspecting the storage dictionaries. copy/deepcopy)

  • snapshots (detached DataSet)

  • state. (and FDH5 export writes one current)

  • a (Boundary conditions remain on problem and are not serialized as)

  • frames. (solver restart. Viewer Reload refreshes this object without creating)

  • and (Modal/buckling problems expose computed modes through n_iter)

  • time. (set_mode; only the selected mode's fields are extracted at a)

fedoo.constitutivelaw.SimcoonThermoMechanical

class SimcoonThermoMechanical(umat_name, props, thermal_conductivity, n_statev=None, reference_temperature=293.15, tangent_mode=2, name='')

Small-strain isotropic Simcoon umat_T material.

props uses the thermal UMAT layout, which differs from the mechanical UMAT layout. For ELISO it is [rho, c_p, E, nu, alpha], with one state variable. Other kernels require an explicit n_statev. This initial adapter accepts the isotropic ELISO, EPICP and EPKCP kernels. Conductivity is supplied separately: umat_T returns a local thermal balance, not a heat flux.

The returned r includes capacity. HeatEquation therefore does not add a second HeatCapacity term. Attach FIRST_ORDER/BackwardEuler to declare the transient thermal problem; umat_T owns this local discretization. The kernel’s derivatives are used as supplied (some are continuum tangents).

Temperatures are necessarily absolute temperatures in kelvin (never degrees Celsius) and must stay strictly positive: set the initial field with pb.set_dof("Temp", T0) before solving. reference_temperature is in kelvin as well.

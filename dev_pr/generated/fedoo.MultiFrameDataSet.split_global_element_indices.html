fedoo.MultiFrameDataSet.split_global_element_indices

MultiFrameDataSet.split_global_element_indices(element_ids) → dict[int, ndarray]

Split global element ids into submesh-local element ids.

Parameters:

element_ids (array-like of int) – Element ids in the concatenated global numbering used by multimesh plotting and viewer selections.

Returns:

Mapping submesh_id -> local_element_ids. Empty submeshes are omitted.

Return type:

dict[int, numpy.ndarray]

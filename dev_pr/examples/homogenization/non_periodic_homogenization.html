Non-periodic homogenization with microgen

Note

This example is too heavy to be run at each documentation build. Its results were precomputed on 2026-11-11 with fedoo 1.1.0, simcoon 0+unknown, ipctk 1.6.0, numpy 2.5.4 (fedoo commit 0c1c3c65c9bdd8702d3f2ad96d75c408d2ffb4d6), in about 49 s (Linux x86_64, BLAS mkl). Run the script to reproduce it with your fedoo version.

Homogenization of a non-periodic spinodoid microstructure using microgen’s BoxMesh to build the boundary interpolation dictionary required by PeriodicBC with meshperio=False.

The effective stiffness tensor is computed using the perturbation method (get_homogenized_stiffness / get_tangent_stiffness).

This example requires microgen (pip install microgen), version 1.3 or later: the boundary keys of BoxMesh ("x-", "x+y-", "x-y-z+"…) are those expected by fedoo.constraint.PeriodicBC (microgen 1.2 used other names). Only the BoxMesh submodule is used; with microgen 2, it does not require cadquery (microgen 1.x imports cadquery when the package is imported).

import os

import fedoo as fd
import numpy as np
import pyvista as pv
from microgen.box_mesh import BoxMesh

Load the non-periodic mesh

fd.ModelingSpace("3D")

dir_meshes = os.path.join(
    os.path.dirname(os.path.abspath(__file__)), "../../util/meshes/"
)

pvmesh = pv.read(os.path.join(dir_meshes, "spinodoid_pd.vtk"))
mesh = fd.Mesh.from_pyvista(pvmesh, name="Domain")

Build the boundary interpolation dictionary

BoxMesh identifies boundary nodes and computes nearest-neighbour interpolation data for non-matching opposite faces.

box_mesh = BoxMesh.from_pyvista(pvmesh)

# Merge all boundary data into a single dictionary.
# ``closest_points_on_boundaries`` returns "+" side entries as
# ``(indices, distances)`` tuples for interpolation weights.
# ``faces`` / ``edges`` / ``corners`` provide the "-" side plain arrays.
# The "+" keys from ``closest_points`` overwrite the plain "+" arrays.
dic = {}
dic.update(box_mesh.faces)
dic.update(box_mesh.edges)
dic.update(box_mesh.corners)
dic.update(box_mesh.closest_points_on_boundaries(k_neighbours=3))
dic["rve_size"] = list(box_mesh.rve.dim)

Material, weak formulation and assembly

material = fd.constitutivelaw.ElasticIsotrop(1e5, 0.3)
wf = fd.weakform.StressEquilibrium(material, nlgeom=False)
assemb = fd.Assembly.create(wf, mesh, mesh.elm_type, name="Assembly")

Compute the effective stiffness tensor

The 6 x 6 stiffness matrix is computed by the perturbation method: one linear problem per mean strain component.

L_eff = fd.homogen.get_homogenized_stiffness(
    assemb,
    meshperio=False,
    dic_closest_points_on_boundaries=dic,
)

np.set_printoptions(precision=2, suppress=True)
print("Effective stiffness tensor:")
print(L_eff)

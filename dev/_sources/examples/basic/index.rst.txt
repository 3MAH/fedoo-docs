

.. _sphx_glr_examples_basic:

Basic examples
--------------

Simple examples to get started with fedoo: create meshes, define materials,
apply boundary conditions, solve linear and nonlinear static problems, modal
and linear buckling analyses with solid, beam and shell elements, define a
user equation from its weak form, and post-process the results.
